# User typing style

The user writes short Indonesian messages from a phone keyboard, with typos: "uodate" = update, "c9ba" = coba ("try"), "sufha" = sudah, "darinkernelsu" = dari kernelsu, "brqnch" = branch, "n3st" = next, "lanjutksn" = lanjutkan, "aampai" = sampai. Read the intent, not the literal tokens. A token that looks like a commit hash (e.g. "c9ba") may just be a typo. Check the Indonesian reading first before searching repos for it.

Reply to the user in Indonesian. GitHub release notes, commit messages and CLAUDE.md stay in English.
